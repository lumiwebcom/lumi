lumi for Windows
================

1. Unzip this whole folder somewhere you'll keep it (for example Documents\lumi).
   Keep every file together: lumi.exe needs the files next to it.
2. Double-click lumi.exe.
3. Optional: right-click lumi.exe > "Pin to taskbar" or "Send to > Desktop (create shortcut)".

The first time, Windows may show "Windows protected your PC" because the app
isn't code-signed. Click "More info", then "Run anyway".

Updates
-------
You never need a new exe. The app loads lumi live, so every update reaches it
automatically. When a new version comes out while lumi is open, an "Update"
button appears in the top-right corner: click it to switch to the new version
right away.

Screen sharing
--------------
When you share your screen, lumi asks which screen or window to share.
